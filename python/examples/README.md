# Demo Files

## Quick Start

### 1. Start Server
```bash
python demo_server.py
```

### 2. Run Client (in another terminal)
```bash
python demo_client_upload.py
```

## What It Does

- **demo_server.py** - Starts Node.js server with encryption enabled
- **demo_client_upload.py** - Encrypts a test file, creates packets, uploads to server

## Requirements

- Node.js installed
- Server running before client
- Both use API key: `demo-key-12345`

## Output

Uploaded files saved to: `../demo_uploads/`
